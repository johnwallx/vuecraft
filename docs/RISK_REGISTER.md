# Dependency risk register

Every exception in `deny.toml` is listed here. An exception is an accepted, open risk, not a
resolved one. Review each entry when the depending crate is upgraded and before each release.

The Rust table also tracks one advisory that has no exception: RUSTSEC-2024-0429 (glib), an
"unsound" advisory. `cargo deny check` with this `deny.toml` does not report it; with
`unsound = "all"` added under `[advisories]` it reports it as an error. Open npm advisories from
`pnpm audit` are listed in their own section below. None of them is dismissed or suppressed.

starts at a `devDependencies` entry (lint and test tooling). `pnpm audit --prod` reports no known
vulnerabilities, and `src/` imports none of these packages, so none of them is in the Vite bundle
(`dist/`) or the installer. The constraint column gives the ranges declared by the installed
versions. Whether newer releases of the intermediate packages already allow the patched versions
was not checked. WebdriverIO stays on v9 because `@wdio/tauri-service` 1.5.1 requires
`webdriverio ^9` (`.github/dependabot.yml`), so fixes in the WebdriverIO tree have to arrive as
v9 releases.
